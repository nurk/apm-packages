# cpp-embedded-style

APM package with conventions and helpers for embedded C/C++ development.

## Included primitives

- Skill: `.apm/skills/cpp-embedded-style/SKILL.md`

## Install locally

From the monorepo root:

```bash
apm install ./cpp-embedded-style
```

## Notes

- This package currently has no transitive dependencies.
- Add dependencies in `apm.yml` under `dependencies.apm` when needed.
